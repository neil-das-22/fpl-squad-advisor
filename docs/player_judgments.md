# Player Judgments

Neil's own calls on specific players — the fan judgment layer. These are read by the orchestrator agent alongside the model's xP and the specialist agents' research, and can upgrade, downgrade, or flag a player regardless of what the numbers say. Football isn't fully predictable, and this is the explicit channel for that.

Format per entry:

```
## Player Name
- Date: YYYY-MM-DD
- Call: upgrade | downgrade | avoid | must-have | watch
- Note: why — the reasoning matters more than the label
```

Example:

```
## Erling Haaland
- Date: 2026-08-09
- Call: must-have
- Note: Nails penalties consistently regardless of strike-partner changes; trust his floor more than a pure per-90 number would suggest.
```
